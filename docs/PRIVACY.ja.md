# Ondrift プライバシーポリシー

[English](../PRIVACY.md) | [한국어](PRIVACY.ko.md) | 日本語 | [简体中文](PRIVACY.zh.md)

発効日: 2026年8月24日

Ondrift は Ondrift Labs が公開する Chrome 拡張機能です。ChatGPT、Claude、
Gemini、Perplexity、Grok でプロンプトを送信する前に、書き直しとスコアリングを
行います。本ポリシーは Ondrift Free MVP が扱うデータについて説明します。

## Ondrift が扱うデータ

Ondrift はユーザー向け機能の提供に必要な情報のみを扱います。

- ユーザーが入力した Gemini API キー
- ユーザーが明示的に書き直しを要求したプロンプトのテキスト
- 書き直し時に生成される、改善されたプロンプト、スコア、根拠、対応サイトの URL、適用状況、タイムスタンプ、Gemini のトークン数
- 言語、ペルソナ、有効化されたサイト、ローカル履歴設定などの拡張機能の設定
- 無料プランの日次上限を適用するためにランダム生成されるインストール識別子。無料プランのサービスは、上限の適用に必要な IP アドレスなど通常のネットワークリクエスト情報も受信します。

Ondrift は、AI の応答本文、認証クッキー、ユーザーが送信しなかったメッセージ、
対応外のウェブサイトのコンテンツを読み取ったり保存したりすることはありません。

## データの利用と共有方法

ユーザーが自分の Gemini API キーを追加した状態で **書き直してスコアを表示** を
選択すると、選択されたプロンプトとそのキーは、拡張機能のサービスワーカーから
HTTPS 経由で Google の Gemini API に直接送信されます。この場合、Ondrift の
サーバーは関与せず、キー、プロンプト、書き直し結果を受信しません。当該リクエスト
に対する Google の取り扱いは、ユーザーと Google との契約、および Google の該当する
API 利用規約とプライバシーポリシーに準拠します。

ユーザーが Gemini API キーを追加していない場合、選択されたプロンプト、対応
サービス、ペルソナ、言語、ランダムなインストール識別子は、HTTPS 経由で
`ondrift.pages.dev` の Ondrift Cloudflare Pages Function に送信されます。この関数は
Ondrift の API キーを使って書き直しリクエストを Google Gemini に転送し、結果を
返します。この経路は、1日3回の無料プランを提供し、インストール単位または IP 単位の
上限を適用する目的にのみ使用されます。

Ondrift はユーザーデータを販売せず、広告目的に利用せず、サイトをまたぐ
トラッキングを行わず、人がデータを閲覧できるようにすることもありません。
ローカル履歴は Ondrift のサービスに送信されません。

## ローカル保存と保持

API キーと拡張機能の設定は、`chrome.storage.local` を使用してユーザーの
ローカル Chrome プロファイルに保存されます。ローカル履歴機能が有効な場合、
書き直し履歴は同じデバイス上の拡張機能専用の IndexedDB に保存されます。
Ondrift は Chrome の同期ストレージや開発者が運営するクラウドストレージを
使用しません。

ローカル設定と履歴は、ユーザーが変更または削除するまで保持されます。ユーザーは
個々の対応サイトを無効化したり、履歴機能をオフにしたり、個々の履歴項目を
削除したり、すべての履歴を消去したり、API キーを交換したり、拡張機能を削除したり
できます。拡張機能を削除すると、Chrome の拡張機能データの取り扱いに従って、
拡張機能専用のローカルデータも削除されます。

## 権限

- `storage` 権限は、ユーザーのキー、設定、環境設定をローカルの Chrome プロファイルに保存するために使用されます。
- ChatGPT、Claude、Gemini、Perplexity、Grok へのアクセスは、プロンプト入力欄の検出、Ondrift コントロールの表示、ユーザーが書き直しを要求した後のプロンプトの読み取り、承認された書き直しの適用にのみ使用されます。
- `generativelanguage.googleapis.com` へのアクセスは、自分のキーを提供したユーザーが要求した Gemini API 呼び出しの実行にのみ使用されます。
- `ondrift.pages.dev` へのアクセスは、ユーザーが Gemini API キーを提供していない場合の無料プランの書き直しリクエストにのみ使用されます。

## セキュリティ

Gemini または Ondrift の Cloudflare Pages Function に送信されるデータは HTTPS 経由で送信されます。Ondrift は単一の目的に
必要な Chrome 権限のみを要求し、リモートでホストされるコードを実行することは
ありません。ユーザーは自身の Chrome プロファイルへのアクセスを保護する必要が
あり、いつでも Google AI Studio を通じて Gemini API キーを取り消したり
交換したりできます。

## Limited Use(限定的利用)

Google API から受け取った情報の利用は、Limited Use の要件を含む Chrome
ウェブストアのユーザーデータポリシーに従います。

## 変更とお問い合わせ

本ポリシーに重要な変更がある場合、変更されたデータの取り扱いが適用される前に、
発効日を更新し、変更後のポリシーを公開することで反映します。プライバシーまたは
サポートに関するお問い合わせは、Ondrift の Chrome ウェブストア掲載情報に表示
されている、確認済みの公開者連絡先またはサポートチャネルをご利用ください。
