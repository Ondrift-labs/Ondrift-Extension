## Reddit: r/SideProject launch and feedback post

Status: ready after a live rules check and browser connection

Title:

> I built a local-first prompt rewriter for ChatGPT, Claude, Gemini, and Perplexity

Body:

> I kept getting vague answers, then realized half the problem was the vague prompt I had typed five seconds earlier. Turns out the model was following my instructions perfectly, which felt a little rude.
>
> So I built Ondrift. It is a Chrome extension that sits inside ChatGPT, Claude, Gemini, and Perplexity. It scores the prompt you are typing, points out missing context or constraints, and suggests a rewrite you can apply without moving to another tab.
>
> I did not want to run another account system or collect prompts. Ondrift uses your own Gemini API key, sends only the prompt you choose directly to Gemini, and keeps its settings and optional history in your browser.
>
> The tradeoff is setup: you need to bring an API key, and the current MVP installs from GitHub while I prepare the Chrome Web Store listing. It supports English, Korean, and Japanese.
>
> I am trying to decide what to improve next:
>
> - Is bringing your own key an acceptable tradeoff for having no Ondrift account or backend?
> - Is the score and explanation useful, or would you rather have a faster one-click rewrite?
>
> I built it, so technical and privacy questions are welcome:
> https://github.com/Ondrift-labs/Ondrift-Extension/releases/latest
