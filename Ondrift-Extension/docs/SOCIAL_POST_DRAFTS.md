## Draft: minimized widget, click vs right-click (theme 2 — small build decision/lesson)

- Status: draft, not reviewed or published
- Target: Threads (adapt separately for Reddit if reused — do not copy verbatim)
- Product facts to re-verify before posting: the minimized widget currently only re-expands via right-click menu; there is no click-to-expand. Confirm this is still true in the release being promoted.

> Shipped a UI decision I went back and forth on: the minimized Ondrift widget used to pop back open if you clicked anywhere near it, which was convenient right up until you were trying to click something else on the page and it expanded instead.
>
> Took the click-to-expand out entirely. Now the only way back is right-click → "Expand," full stop.
>
> Turns out "make it easy to reopen" and "don't hijack clicks meant for the actual page" were the same feature fighting itself. Picked one.
