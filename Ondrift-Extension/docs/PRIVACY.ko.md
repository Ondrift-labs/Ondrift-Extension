# Ondrift 개인정보처리방침

[English](../PRIVACY.md) | 한국어 | [日本語](PRIVACY.ja.md) | [简体中文](PRIVACY.zh.md)

발효일: 2026년 8월 24일

Ondrift는 Ondrift Labs가 배포하는 Chrome 확장 프로그램입니다. ChatGPT, Claude,
Gemini, Perplexity, Grok에서 프롬프트를 전송하기 전에 다시 작성하고 점수를 매기는 데
도움을 줍니다. 이 방침은 Ondrift Free MVP가 다루는 데이터를 설명합니다.

## Ondrift가 다루는 데이터

Ondrift는 사용자 기능 제공에 필요한 정보만 다룹니다.

- 사용자가 입력한 Gemini API 키
- 사용자가 명시적으로 다시 쓰기를 요청한 프롬프트 텍스트
- 다시 쓰기 과정에서 생성되는 개선된 프롬프트, 점수, 근거, 지원 사이트 URL, 적용 상태, 타임스탬프, Gemini 토큰 수
- 언어, 페르소나, 활성화된 사이트, 로컬 기록 설정 등의 확장 프로그램 설정
- 무료 요금제의 일일 한도를 적용하기 위해 무작위로 생성한 설치 식별자. 무료
  요금제 서비스는 한도 적용을 위해 IP 주소를 포함한 일반적인 네트워크 요청
  정보도 수신합니다.

Ondrift는 AI 응답 본문, 인증 쿠키, 사용자가 제출하지 않은 메시지, 지원하지 않는
웹사이트의 콘텐츠를 읽거나 저장하지 않습니다.

## 데이터 사용 및 공유 방식

사용자가 자신의 Gemini API 키를 추가한 상태에서 **다시 쓰기 및 점수 매기기**를
선택하면 선택된 프롬프트와 해당 키가 확장 프로그램 서비스 워커에서 HTTPS를 통해
Google의 Gemini API로 직접 전송됩니다. 이 경우 Ondrift 서버는 관여하지 않으며 키,
프롬프트 또는 다시 쓰기 결과를 수신하지 않습니다. 해당 요청에 대한 Google의 처리
방식은 사용자와 Google 간의 계약 및 Google의 API 약관과 개인정보처리방침에
따릅니다.

사용자가 Gemini API 키를 추가하지 않은 경우 선택된 프롬프트, 지원 서비스,
페르소나, 언어 및 무작위 설치 식별자가 HTTPS를 통해 `ondrift.pages.dev`의 Ondrift
Cloudflare Pages Function으로 전송됩니다. 이 함수는 Ondrift의 API 키를 사용해 다시
쓰기 요청을 Google Gemini로 전달하고 결과를 반환합니다. 이 경로는 하루 3회의 무료
요금제를 제공하고 설치별 또는 IP별 한도를 적용하는 용도로만 사용됩니다.

Ondrift는 사용자 데이터를 판매하거나 광고 목적으로 사용하거나 사이트 간 추적을
수행하거나 사람이 데이터를 열람하도록 허용하지 않습니다. 로컬 기록은 Ondrift
서비스로 전송되지 않습니다.

## 로컬 저장 및 보관

API 키와 확장 프로그램 설정은 `chrome.storage.local`을 사용해 사용자의 로컬
Chrome 프로필에 저장됩니다. 로컬 기록 기능이 켜져 있으면 다시 쓰기 기록은 동일
기기의 확장 프로그램 전용 IndexedDB에 저장됩니다. Ondrift는 Chrome 동기화
저장소나 개발자가 운영하는 클라우드 저장소를 사용하지 않습니다.

로컬 설정과 기록은 사용자가 변경하거나 삭제하기 전까지 유지됩니다. 사용자는 개별
지원 사이트를 비활성화하거나, 기록 기능을 끄거나, 개별 기록 항목을 삭제하거나,
전체 기록을 지우거나, API 키를 교체하거나, 확장 프로그램을 제거할 수 있습니다.
확장 프로그램을 제거하면 Chrome의 확장 프로그램 데이터 처리 방식에 따라
확장 프로그램 전용 로컬 데이터가 함께 제거됩니다.

## 권한

- `storage` 권한은 사용자의 키, 설정, 환경설정을 로컬 Chrome 프로필에 저장하는 데 사용됩니다.
- ChatGPT, Claude, Gemini, Perplexity, Grok에 대한 접근 권한은 프롬프트 입력창을 감지하고, Ondrift 컨트롤을 표시하고, 사용자가 다시 쓰기를 요청한 후 프롬프트를 읽고, 승인된 다시 쓰기를 적용하는 데에만 사용됩니다.
- `generativelanguage.googleapis.com`에 대한 접근 권한은 자신의 키를 제공한 사용자가 요청한 Gemini API 호출을 수행하는 데에만 사용됩니다.
- `ondrift.pages.dev`에 대한 접근 권한은 사용자가 Gemini API 키를 제공하지 않은 경우의 무료 요금제 다시 쓰기 요청에만 사용됩니다.

## 보안

Gemini 또는 Ondrift의 Cloudflare Pages Function으로 전송되는 데이터는 HTTPS를 통해 전송됩니다. Ondrift는 단일 목적에 필요한
Chrome 권한만 요청하며 원격에서 호스팅되는 코드를 실행하지 않습니다. 사용자는
자신의 Chrome 프로필에 대한 접근을 보호해야 하며, 언제든지 Google AI Studio를
통해 Gemini API 키를 취소하거나 교체할 수 있습니다.

## 제한된 사용

Google API에서 수신한 정보의 사용은 Limited Use 요건을 포함한 Chrome 웹 스토어
사용자 데이터 정책을 따릅니다.

## 변경 사항 및 문의

이 방침에 중대한 변경이 있을 경우 변경된 데이터 처리 방식이 적용되기 전에
발효일을 갱신하고 변경된 방침을 게시하여 반영합니다. 개인정보 또는 지원 관련
문의는 Ondrift의 Chrome 웹 스토어 등록 정보에 표시된 인증된 게시자 연락처 또는
지원 채널을 이용해 주세요.
